# AlwayRoute v1 RPC 契约

LuCI session RPC 对象 `alwayroute`；所有方法返回 `{ok:true,...}` 或
`{ok:false,error:{code,message,details?}}`。生产不使用 fixture 回退。

| 方法 | 参数 | 成功数据 |
|---|---|---|
| capabilities | 无 | schema:1, protocols, subscriptionFormats, limits, forwarding |
| get | 无 | model, state |
| save | expectedRevision:number, model:object | model, state |
| refresh | expectedRevision:number, subscriptionId:string, content:string(可空，空则HTTPS抓取) | model, state, imported:number |
| apply | expectedRevision:number | state |
| select | expectedRevision:number, group:string, nodeId:string | model, state（仅保存，须apply生效） |
| status | 无 | state, service, core, forwarding |
| traffic | 无 | available:boolean, upload:number或null, download:number或null, unit:"bytes/s", reason? |
| rollback | expectedRevision:number | model, state |
| service | action:"start"或"stop" | state |
| export | includeSecrets:boolean（默认false） | model, redacted:boolean |
| import | expectedRevision:number, content:string | model, state, imported:number（导入为手动节点） |
| check | nodeId:string | 后台job，完成job.result含nodeId/available/delay毫秒/healthy/checkedRevision |
| logs | limit:1..20 | entries:[{time,level,message}]（仅脱敏管理事件） |
| job_status | 无 | busy:boolean, job:{id,method,status,started,finished?,error?,state?,result?}或null |

`state={savedRevision,appliedRevision,healthy:"unverified"|"passed"|"failed",lastError?}`。
saved 与 applied 独立，进程存活不代表节点健康。修改须 expectedRevision；并发冲突返回
REVISION_CONFLICT；持锁时 BUSY。apply/refresh/rollback/check/service均异步，立即返回
`{ok:true,job:{id,method,status:"running",started}}`。轮询job_status，校验id，
status为succeeded或failed后结束；完成后重新get/status。失败详见job.error；
只有check通过job.result返回脱敏结果，job_status不返回含凭证model。worker超时/中断显示JOB_INTERRUPTED。
apply 经 sing-box check、重启及loopback API读取确认；不等同出口验证。

模型：`{schema:1,revision:0,mode:"rule"|"global"|"direct",defaultOutbound:"Proxy",
nodes:[],subscriptions:[],overrides:{},groups:[],rules:[]}`。
节点 `{id,name,type:"vmess",enabled:true,source:null或订阅ID,sourceKey?:string,
server,port,uuid,security:"auto",alterId:0,tls?:{enabled,serverName},
transport?:{type:"ws",path,host}}`。id 为 `[A-Za-z0-9_-]{1,64}`，引用使用id。
groups `{id:"Proxy"|"OpenAI"|"Netflix"|"Disney"等,name,selected:"direct"或nodeID}`。
非Proxy组还可selected="Proxy"单层跟随，阻止循环；默认三个业务组跟随Proxy。
规则按数组次序首条匹配：`{id,enabled:true,type:"domain"|"suffix"|"ip"|"cidr",value,outbound}`；
outbound 为 direct/block/节点ID/groupID。IP是IPv4，CIDR是IPv4（IPv6输入明确不支持）。
订阅 `{id,name,url,enabled:true,intervalHours:0或1..168,lastUpdate?,lastError?}`。
overrides 以订阅节点ID为键：`{excluded?:true,name?:string,patch?:{server?,port?,uuid?,security?,alterId?,tls?,transport?}}`。
订阅节点以协议+server+port+uuid的SHA256前24位生成 sourceKey，稳定ID=`s_<订阅ID>_<sourceKey>`；
更名不变ID，连接身份变动视作新节点。失败保持旧数据；引用消失时拒绝更新，提示先处理引用。

限制：VMess URI列表（可整体base64）；Clash JSON 的proxies数组；严格Clash YAML块列表子集，
仅 proxies / VMess 标量及tls/ws-opts；拒绝锚点、标签、多行、flow map、未知协议/字段、udp:false。
真实支持范围由capabilities返回。有限输入128KiB/128节点/128规则/16订阅，禁止任意sing-box透传。
凭证仅授权编辑及显式完整导出返回；普通状态/错误不包含URL/uuid/响应正文。
DNS采用代理出口DoH+本地bootstrap，缓存512、IPv4-only；直连域名走bootstrap，
LAN 53端口由独立转发适配器截获。DNS/nft接管另由适配层集成；capabilities.forwarding=unverified 直至实测。
get含凭证，只授予write ACL；status/traffic/logs/job_status可授予read ACL。
