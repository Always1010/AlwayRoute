# AlwayRoute v1 RPC 契约

LuCI session RPC 对象 `alwayroute`；所有方法返回 `{ok:true,...}` 或
`{ok:false,error:{code,message,details?}}`。生产不使用 fixture 回退。

| 方法 | 参数 | 成功数据 |
|---|---|---|
| capabilities | 无 | schema:1, protocols, subscriptionFormats, limits, forwarding, policyPresets |
| get | 无 | model, state |
| save | expectedRevision:number, model:object | model, state |
| configure | expectedRevision:number, model:object | 后台job；运行时确认核心/转发后同时提交model与state；停止时校验并保存下次启动配置 |
| refresh | expectedRevision:number, subscriptionId:string, content:string(可空，空则HTTPS抓取), activate?:boolean | 后台job；默认仅保存；activate:true时确认后即时提交 |
| apply | expectedRevision:number | state |
| select | expectedRevision:number, group:string, nodeId:string | model, state（仅保存，须apply生效） |
| status | 无 | state, service, core, forwarding |
| traffic | 无 | available:boolean, upload:number或null, download:number或null, unit:"bytes/s", reason? |
| rollback | expectedRevision:number | model, state |
| service | action:"start"或"stop" | state |
| export | includeSecrets:boolean（默认false） | model, redacted:boolean |
| import | expectedRevision:number, content:string, activate?:boolean | 默认model/state/imported:number（导入为手动节点）；activate:true时后台job确认后即时提交 |
| check | nodeId?:string, subscriptionId?:string（二选一） | 后台串行job；单节点兼容原nodeId/available/delay毫秒/healthy/checkedRevision；整订阅返回checks及total/completed/passed/failed/cancelled；配置未应用或服务停止则NOT_APPLIED |
| cancel_check | jobId:string | cancelling:true，仅接受当前running检测的id；免事务锁写入取消标志，不杀核心或worker |
| logs | limit:1..20 | entries:[{time,level,message}]（仅脱敏管理事件） |
| job_status | 无 | busy:boolean, job:{id,method,status,started,finished?,error?,state?,result?,progress?}或null；检测progress含total/completed/passed/failed/currentNodeId |

`state={savedRevision,appliedRevision,healthy:"unverified"|"passed"|"failed",lastError?}`。
saved 与 applied 独立，进程存活不代表节点健康。修改须 expectedRevision；并发冲突返回
REVISION_CONFLICT；持锁时 BUSY。configure/apply/refresh/rollback/check/service均异步，立即返回
`{ok:true,job:{id,method,status:"running",started}}`。轮询job_status，校验id，
status为succeeded、failed或检测的cancelled后结束；完成后重新get/status。失败详见job.error；
只有check通过job.result返回脱敏结果，job_status不返回含凭证model。worker超时/中断显示JOB_INTERRUPTED。
apply 经 sing-box check、重启及loopback API读取确认；不等同出口验证。

检测复用已运行核心的单节点delay API，串行访问固定HTTPS小请求，每节点核心超时2秒、外部watchdog 3秒。
整订阅仅检测已启用且未排除的已加载节点，不下载订阅、不应用配置、不切换出口、不重启核心。
取消为协作式：等待当前一次有界探测返回后停止，保留本次已完成结果；取消确认不等于已停止，须等job终态。
结果与进度只写/tmp，关联appliedRevision；HTTP探测成功不保证所有网站或UDP可用，失败可能由测试站或网络故障造成。
页面刷新可恢复检测进度及取消入口，检测任务等待上限600秒，其余任务仍120秒；界面超时不取消后台任务。

模式、策略选择与编辑使用 `configure` 提交完整模型；后台事务校验 expectedRevision、
normalize后的模型及模型revision，成功后revision递增一次。服务运行时，候选先通过
sing-box check、核心selector实际选择及转发activate确认，之后才提交current/lastgood；
任一步失败（包括current写入失败）均恢复旧current并尝试恢复旧运行配置，恢复失败保持故障阻断。
服务停止时只执行核心配置校验和保存，保持停止与原启停设置；`service.start` 使用最新current，
确认启动后更新lastgood和appliedRevision。`service.stop` 成功后appliedRevision为null。
界面在job succeeded后重新get/status确认；job失败不能展示候选已生效。旧save/select仍仅保存，
旧apply保留显式应用行为。policyPresets为 `{id,name,default,description,domains:[],exactDomains:[]}` 数组，
数据来自包内唯一正式服务目录 `/usr/share/alwayroute/policies/`，供编辑器展示服务组与用途。

首页导入与订阅更新传 `activate:true`；解析所得候选在同一事务中执行configure的校验和确认流程，
不会先保存节点列表再分步应用。import在activate:true时也异步；失败保留原节点和current，
服务停止时只校验保存并保持停止。activate缺失或false保持原接口仅保存行为，定时订阅更新不自动应用。

模型：`{schema:1,policyVersion:2,revision:0,mode:"rule"|"global"|"direct",defaultOutbound:"Other",
nodes:[],subscriptions:[],overrides:{},groups:[],rules:[]}`。
节点 `{id,name,type:"vmess",enabled:true,source:null或订阅ID,sourceKey?:string,
server,port,uuid,security:"auto",alterId:0,tls?:{enabled,serverName},
transport?:{type:"ws",path,host}}`。id 为 `[A-Za-z0-9_-]{1,64}`，引用使用id。
groups `{id:"Proxy"|"OpenAI"|"Claude"|"Google"|"YouTube"|"X"|"Telegram"|"Other"等,name,selected:"direct"或nodeID}`。
默认创建 Proxy、OpenAI、Claude、Google、YouTube、TikTok、X、Telegram、Domestic、Other 共10组；
Proxy与Other必须保留，Other始终位于数组末尾。Domestic初始direct，非Proxy组还可
selected="Proxy"单层跟随，阻止循环；默认业务组跟随Proxy，Other默认direct并负责规则模式最终出口。
只有Other还可selected="block"；核心selector中对应direct，规则末尾reject保证未命中流量被拒绝。
业务域名来自policyPresets，每个服务用一个包含精确域名与后缀列表的匹配块，不占自定义规则额度。
自定义规则先匹配，YouTube在Google之前，Domestic在专属业务及Proxy境外预设之后。
Proxy承接未被专属组匹配的境外预设服务域名；Domestic不并入Proxy，最终未匹配流量交给Other。
不含policyVersion的旧配置在读取时规范化，迁移最终出口到Other并合并旧GitHub/Netflix/Disney/Spotify组；
保留自定义组，当前版本不补回用户删除的业务组。组已满且无法加入Other时返回MIGRATION_REQUIRED。
policyVersion 1 升级为 2 时，在容量允许时补入 TikTok／Domestic，保留已有组选择。
仅当旧通用服务规则仍启用，类型／域名／出口均匹配正式目录，且 ID 与原自动生成算法一致时移除重复规则；
被编辑、停用或自行添加的规则保留。读取时规范化，下一次 configure 保存新版模型，不直接覆盖设备文件。
规则按数组次序首条匹配：`{id,enabled:true,type:"domain"|"suffix"|"regex"|"ip"|"cidr",values:[],outbound}`；
每条最多128个非空、无重复值，旧单值字段 value 仍兼容，value 与 values 必须恰有一个。
多值生成一个匹配块；regex使用核心domain_regex，语法由应用阶段的sing-box check校验。
outbound 为 direct/block/节点ID/groupID。IP是IPv4，CIDR是IPv4（IPv6输入明确不支持）。
规则模式下，启用的域名规则及内置服务域名按相同顺序生成 DNS 规则；出口为 direct、
或策略组当前选择最终为 direct（包括单层跟随 Proxy）时使用本机 DNS，其余使用代理 DNS。
显式代理例外保留在后续直连域名规则之前；停用规则及 IP/CIDR 规则不生成域名 DNS 规则。
组选择通过 configure 应用后同步重建 DNS 规则；全局／直连模式不应用这些业务 DNS 规则。
订阅 `{id,name,url,enabled:true,intervalHours:0或1..168,allowHttp?:false,lastUpdate?,lastError?}`。
URL默认仅允许https://，保留证书校验；仅此订阅allowHttp===true时允许http://输入。
HTTP凭证与正文没有传输加密，例外必须由管理者对此来源显式开启；旧HTTP配置无flag拒绝。
固定uclient-fetch自动跟随最多10次重定向且无CLI禁用选项，首版无法保证重定向链禁止HTTPS降级；
controller严格校验初始URL协议，不接受其他scheme，不加入未支持的CLI参数。
overrides 以订阅节点ID为键：`{excluded?:true,name?:string,patch?:{server?,port?,uuid?,security?,alterId?,tls?,transport?}}`。
订阅节点以协议+server+port+uuid的SHA256前24位生成 sourceKey，稳定ID=`s_<订阅ID>_<sourceKey>`；
更名不变ID，连接身份变动视作新节点。失败保持旧数据；引用消失时拒绝更新，提示先处理引用。

限制：VMess URI列表（可整体base64）；Clash JSON 的proxies数组；严格Clash YAML块列表子集，
完整Clash YAML只导入顶层proxies块，其他监听、secret、proxy-groups及rules全部忽略不透传。
节点支持块形式及单行flow map标量（引号、转义、逗号和冒号经字符扫描），
以及块形式tls/ws-opts；拒绝锚点、标签、多行字符串、嵌套flow结构、未知节点协议/字段、udp:false。
真实支持范围由capabilities返回。有限输入128KiB/128节点/512条自定义规则/每规则128值/16订阅，禁止任意sing-box透传。
凭证仅授权编辑及显式完整导出返回；普通状态/错误不包含URL/uuid/响应正文。
DNS采用代理出口DoH+本地bootstrap，缓存512、IPv4-only；直连域名走bootstrap，
LAN 53端口由独立转发适配器截获。DNS/nft接管另由适配层集成；capabilities.forwarding=unverified 直至实测。
get含凭证，只授予write ACL；status/traffic/logs/job_status可授予read ACL。
