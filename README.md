# AlwayRoute

让连接小米路由器 4A 的设备通过路由器统一使用代理服务，并提供独立的 Web 管理入口，管理节点、订阅、分流规则、运行状态和流量。

## 项目目标

- 终端设备正常连接路由器即可按规则使用代理，无需逐台安装客户端或配置代理。
- 用户可以通过网页添加、编辑、删除和切换代理节点，管理订阅与分流规则。
- 网页中的配置能够保存、应用到实际转发程序，并在重启后恢复；配置应用失败时能够回退。
- 优先使用已有硬件，目标是由 4A 独立运行；Rock 5B 暂作部署、检查和备份主机。

## 两条实施路径

| 路径 | 方向 | 当前状态 |
| --- | --- | --- |
| A：刷入新固件 | 自编 OpenWrt、sing-box 与轻量 LuCI 管理扩展 | 最终集成镜像已升级，配置与代理自动恢复；用户确认 Wi-Fi、管理页面及日常上网正常，负载继续验收 |
| B：保留小米固件 | 原厂网络功能加核心／管理服务 | 历史备选；保留原厂镜像、备份与兼容性试验记录 |

用户已选择自编固件主线。ShellCrash、Mihomo、OpenClash 等前期候选与比较结论保留在历史报告中。

已有配置管理、LuCI 页面和透明转发包源码。实机已完成真实订阅导入 38 个 VMess 节点、选择应用、LAN DNS、透明 HTTPS、故障阻断与恢复、规则阻断及配置回退；最终集成镜像已保留配置升级并自动恢复。2026-10-23 用户确认终端 Wi-Fi、管理页面及日常上网正常；物理断开 Rock 和负载仍待验收。Rock 仅承担开发、构建与操作职责。

## 文件组织

自有应用与构建配方位于 [firmware](firmware/README.md)，前后端契约位于 `contracts/`，针对性验证位于 `tests/`。源码保存在电脑仓库，通过 rsync 同步到 Rock；第三方源码及构建缓存留在 Rock。

```text
AlwayRoute/
├── README.md                 # 项目概览、当前进度和完整文档导航
├── .gitignore                # 凭证、备份、下载物和本地记录的排除规则
├── firmware/                 # 验证固件的包配方、配置、首启脚本和补丁
├── contracts/                # 管理模型、RPC 契约和脱敏样本
├── tests/                    # 配置事务、界面及集成检查
├── scripts/                  # 源码同步等项目工作流脚本
└── docs/
    ├── requirements.md       # 需求与验收标准
    ├── implementation-plan.md # 当前实施方案
    ├── development-workflow.md # 本地源码与 Rock 构建同步约定
    ├── devices/              # 持续更新的设备与网络记录
    ├── proposals/            # 可行性调查、候选方案及历史提案
    └── reports/              # 按日期保存的执行与验证报告
```

新增执行报告与提案使用 `YYYY-MM-DD-主题.md` 命名，并在文首说明日期、状态和关联文档；同日存在多轮记录时，注明前后关系。需求、当前方案与设备记录在原文件持续维护，新增文档同步加入上方导航。

## 当前进度

截至 2026-10-23（Asia/Shanghai），4A 已运行自编 OpenWrt 25.12.6／Linux 6.12.112，SSH 122、公钥认证、WAN DHCP、HTTPS 上网和一次持久化重启通过。原 Wi-Fi 名称／密码已恢复，LuCI 登录认证已验证并仅向 LAN／回环开放。基础候选首启可写空间为 1500KiB（约 1.465MiB），低于此前 1.5MiB 规划目标；完整组件和更新峰值仍须实测。

三个自有包已实现并集成初版：`alwayroute-manager`、`luci-app-alwayroute`、`alwayroute-forwarding`。最终固件为 13,435,470 字节，244 项镜像检查通过，已完成保留配置升级及代理自动恢复。最终 overlay 可用约 1492 KiB，核心 RSS 一次采样约 29 MiB；仍低于此前 1.5 MiB 可用空间规划值。尚未证明 200Mbps 代理吞吐，当前 Rock 到 4A 的物理链路为 100Mbps。启动首轮 DNS/节点检查出现瞬时超时，未改配置后复测恢复，记录于构建报告。

节点失败时不自动改走直连；核心整体故障时保守阻断公网 TCP/UDP，也会影响公网 direct 规则，LAN 管理仍保留。首版不支持把全部 Clash 功能或无限规则库直接搬入这台 16MB Flash／约 124MB RAM 的设备，实际边界见集成报告。

早期 XMiR-Patcher 中断及取消的验证属于历史记录；前次降级／root 操作另有报告。本轮通过现有密钥登录，没有重复漏洞利用。早期中断不能独自证明 2.28.91 完整利用链失效。

管理密码、订阅凭证、节点密钥和设备完整备份不得提交到仓库。本文与方案文档仅记录需求和规划，不代表授权执行解锁、安装、网络变更或刷机。
