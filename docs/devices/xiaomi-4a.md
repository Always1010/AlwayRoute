# 小米 4A 设备信息

本文维护 AlwayRoute 使用的小米 4A 路由器信息、访问方式及相关网络状态。实测结果、官方型号规格和待确认事项分别记录，避免将型号资料当作本机实测值。

- 最后更新：2026-10-22（Asia/Shanghai）
- 当前阶段：可行性评估与现成方案调研
- 当前目标：优先评估由 4A 独立提供局域网统一代理和 Web 管理的方案；Rock 5B 暂作操作与检查主机
- 变更状态：尚未对 4A 执行解锁、安装代理或刷机；已获授权并完成 Rock 5B 的管理网络调整

| 项目 | 记录 | 信息来源 |

| 设备 | 小米路由器 4A，接口标识与官方千兆版资料一致 | 路由器接口与小米官方规格交叉核对 |
| 硬件标识 | `R4A` | 本机基础信息接口实测 |

| 固件版本 | `2.28.91` | 本机基础信息接口实测 |

| 项目 | 官方型号规格 |
| --- | --- |
| 处理器 | MediaTek MT7621A |
| 内存 | 128MB DDR3 |
| 闪存 | 16MB NOR Flash |
| 网络接口 | 两个千兆 LAN 口、一个千兆 WAN 口 |
| 无线网络 | 2.4GHz 与 5GHz 双频 |

具体 Linux 内核版本、闪存芯片、分区布局、空闲内存和剩余可写空间均未取得。此前在 SSH 检查中看到的 `Linux 6.1.0-1025-rockchip` 属于 Rock 5B，不是 4A。

## 5. 后续操作前的关键未确认事项

- 4A 的物理硬件修订及闪存芯片。
- 原厂固件 `2.28.91` 对应的可靠权限获取方式。
- 路由器实际内核、分区布局、可写空间和内存余量。
- 4A 当前上联接线、WAN 状态及互联网连通性。
- 现有代理节点的协议与订阅格式；无需在本文件保存订阅凭证。
- 满足这些条件后，比较“原厂固件＋ShellCrash”与“OpenWrt＋现成插件”，尚未选定实施方案。

地址规划必须提前处理：B 已使用 `192.168.1.1/24`，而 OpenWrt 常见初始 LAN 地址也是 `192.168.1.1`。首次启动或恢复阶段，不应未经隔离设计就让 Rock 的有线口与 Wi-Fi 同时连接两个重叠的 `192.168.1.0/24` 网络。电脑还存在使用 `192.168.1.1` 的 VMware 虚拟接口，当前访问 Rock 的实测路径正常，但后续网络变化仍需核对。

## 6. 维护规则

- 设备型号、地址、固件、SSH 状态或接线变化后，更新对应条目和最后检查日期。
