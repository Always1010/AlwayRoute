## 新增报告约定

文首记录日期／时区、范围、状态、对应源码提交、相关输入哈希、前序和后续关系。正文分别写执行事实、测试条件、结果及覆盖边界。公开报告保留版本、必要设备规格、脱敏统计和校验和；运行UUID、个人主机身份、SSID、真实密钥／备份位置与原始配置留私有资料。

失效候选保留明确失败条件，不进入当前步骤；重复流水账优先归纳到既有报告，不为每次命令生成一篇文档。历史提交引用继续保留，移动文件时同步检查所有链接。
