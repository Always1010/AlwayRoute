## 执行边界

电脑保存自有源码、配方、补丁及文档；Rock复用现有构建树、下载、工具链、Go模块和编译缓存。组件改动先做针对性检查及构建，稳定后集中重新打包镜像，不例行clean。设备写入、构建树写入和Git提交各保持唯一操作者，避免相互覆盖。

当前核心与管理功能必须保留。性能候选另存产物与身份，任何差分、稳定性或恢复检查失败都停止候选，不把精简功能当作原需求已经满足。节点故障按已确定策略阻断，核心故障时保留LAN管理。

环境选择、源码同步、status和stage不构成刷机。安装依赖、修改本机网络／服务及实际部署仍遵守对话授权和[协作规则](../AGENTS.md)。文档中的历史授权不是未来操作许可。修改后按范围验证，创建目的独立的本地中文Conventional Commit；未经当前请求明确要求不push。
