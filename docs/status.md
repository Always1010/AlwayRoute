## 性能与明确限制

[Flash 核心复测](reports/2026-10-23-flash-core-retest.md)使用4并发、180秒并附短请求：VMess TCP 167.22 Mbps、WS/TLS 156.43 Mbps，Other 经核心直连479.94 Mbps，关闭代理的局域网 NAT 回环718.15 Mbps。实际 WAN 公网下载另测为198.60 Mbps；它和局域网回环的路径不同。四策略组并发163.94 Mbps，双向合计167.57 Mbps。该报告早于最新服务规则 ROM 更新，不能当作最后一次 ROM 的重新压测。

千兆物理链路不能证明千兆加密吞吐，目前没有稳定200 Mbps代理达标证据。[未通过稳定性验收的性能实验](reports/2026-10-23-200m-feasibility.md)已撤回；此前精简 CLI／注册表／selector 的版本也已撤回，生产保留完整功能。

节点故障不会自动切到直连。核心整体故障时，保守阻断会影响公网 direct 规则，LAN 管理仍保留。16MiB Flash／约124MiB可见内存限制了大型规则库、桌面完整配置照搬和高频持久日志。

实际环境资料保存在被 Git 忽略的 `.local/lab/`，不属于项目默认配置。
